# 优化说明

评审日期：2026-11-03。参考项目：[beautfulmt/PM-K12--skills](https://github.com/beautfulmt/PM-K12--skills)。本版为通用轻量工作流，不增加 K12 专属规则。

## 优先处理的问题

1. **模拟资料与真实证据的边界不足**：原 `assets/workflows/edu-pm-demand.md` 的数据收集步骤允许模拟典型用户反馈，之后接痛点聚类和机会分析。轻量版要求模拟内容标为示例，不能计入真实证据；没有材料时先列假设及验证计划。
2. **初始化分支有歧义**：原 `SKILL.md` 先说已有 `.agents/workflows/` 就不要初始化，下一条又说缺少所需脚本要安装。轻量版去掉初始化与服务依赖，直接读当前材料和相关参考。
3. **入口承担过多专用细节**：原入口包含剪贴板图像编码、撤销栈、导出审计、颜色和浏览器兼容等规则。轻量版入口仅保留共享约束，阶段细节按需读取。
4. **触发范围偏宽**：原描述同时覆盖产品需求、流程图、checklist、数据分析等。轻量版限定为产品需求分析、PRD 与交互原型，排除普通网页开发、通用数据分析和单纯文案修改。
5. **确认链条偏长**：原 PRD 工作流包含需求反向确认与章节裁剪确认。轻量版只对影响方案的未知信息澄清，不把非阻塞问题变成固定审批。
6. **展示约束强于业务差异**：固定 HTML、表格、描述块、主题与导出流程适合某些团队，但不应成为所有小需求的成本。轻量版默认 Markdown 与离线 HTML，用户格式和已有规范优先。

## 保留与取舍

保留“不虚构指标、范围明确、规则与原型同步、复用已有需求目录”。不保留截图导出服务、后台启动器、Pencil、HTML 编辑器、单独流程图/验收/数据分析工作流。

参考项目包含较完整的可编辑 PRD 与导出功能，适合确有这些需求的团队；本版的目标是减少步骤与依赖，不是实现其全部功能。没有对上游运行时做完整测试，不把静态观察写成已复现的运行缺陷。

下载的参考包中未发现 LICENSE 文件。本版没有复制其代码、模板或说明段落，也未为上游内容指定新的许可。
