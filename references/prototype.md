# 可点击 HTML 原型

输出以 `prototype.html` 为入口的原型，默认 HTML/CSS/JavaScript 内联，无 CDN、网络字体、构建工具或截图服务依赖。已有项目设计规范优先。

[离线起步文件](../assets/prototype-starter.html) 演示两页导航、创建、空态、失败重试及可访问性反馈。它用“演示清单”说明交互方式，不是所有产品的业务模板；仅复用所需结构，按当前需求替换。

## 开始前

先读已有 PRD 的范围、核心规则和状态。没有 PRD 时，提取用户目标、平台和主路径，标明非阻塞假设，直接做用户请求的原型。不要强制先走需求分析或生成一份新 PRD。

## 交互与状态

- 主路径真正可以点通，导航有返回路径；用 hash 或明确的页内状态，不留无反馈的装饰按钮。
- 按需求实现相关空态、加载、成功、输入错误和失败恢复。没有异步流程时不人为加加载动画。
- 演示涉及提交、登录、支付等能力时，清楚标注模拟行为；不调用生产接口。需要持久化时说明保存位置与清除方式，默认会话状态仅存内存。
- 优先使用语义化按钮、表单和标签；支持键盘，保留焦点边框，状态消息用合适的 `aria-live`。输入使用 `textContent` 等安全方式写入，不直接插入 HTML。
- 默认兼顾手机窄屏；重内容区域可横向滚动，主要按钮与文案不应被裁切。
- 刷新、浏览器返回、未知 hash 均有确定结果。原型不保留数据时在页面中说明。

## 检查与交付

有浏览器能力时，实际走完主路径，检查空态、必填校验、失败后重试、返回与刷新；至少查看桌面和手机宽度。检查控制台错误和 PRD 对应规则。需要截图时使用已有浏览器工具；不为截图自动安装后台服务。

没有浏览器能力时做可行的静态检查，明确交互与视觉尚未验证。原型展示的是行为与布局，未实际连接的服务不得标为已实现。
